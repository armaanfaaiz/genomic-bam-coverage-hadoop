⚙️ Hadoop Streaming & Java MapReduce Engine

The job executes PanDepth-style coordinate difference sweeps across mapped splits:

Mapper (mapper.py): Parses CIGAR (M, I, D, N, S) and outputs deltas (pos, +1) and (pos + len, -1).
Reducer (reducer.py): Single-pass prefix sum sweep array computes exact coverage per base in O(N) time with O(1) auxiliary memory.
